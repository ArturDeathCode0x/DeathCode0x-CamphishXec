# Política de segurança

A segurança e a privacidade são prioridades para este projeto.

## Reportar vulnerabilidades
Não publique detalhes exploráveis, dados pessoais, imagens, credenciais ou tokens em uma issue pública.

Quando disponível, utilize **Private vulnerability reporting** na aba **Security** do GitHub para enviar um relato privado ao mantenedor. Se a opção não estiver habilitada, abra uma issue sem detalhes exploráveis solicitando um canal privado.

## Dados sensíveis
Ao relatar um problema, remova ou substitua senhas, tokens, chaves, dados de localização, imagens de terceiros, identificadores pessoais, cookies e arquivos de sessão.

Testes devem se limitar ao próprio repositório e a ambientes autorizados.
